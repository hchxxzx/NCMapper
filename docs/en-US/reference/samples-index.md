## Reference Contracts

1. DFM references within documentation follow a uniform pattern: `[!code-csharp]` tag + `](~/samples/NCMapper.Samples/<domain-directory>/<file>.cs#<RegionName>)`, where the region name is used directly and the `title` attribute is mandatory.
2. Line-number ranges (`#L`) represent a transitional form that has been zero-based; such ranges are no longer recorded in this table.
3. Scenario IDs are newly assigned as three-digit domain codes (domain ID × 100 + sequence number); an invalid scenario ID corresponds to a registry lookup failure (exit code 2).
